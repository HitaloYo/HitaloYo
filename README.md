### Sobre mim

Trabalho na **Contreina** desenvolvendo os sistemas internos usados no atendimento a prefeituras e câmaras municipais: backend em **Go**, frontend em **Vue 3 / Nuxt** e banco **SQLite**.

No dia a dia, isso inclui:

- **Monitoramento de disponibilidade** de centenas de portais e sistemas web, com confirmação de queda por checagens repetidas e notificações em tempo real via WebSocket.
- **Login compartilhado** entre sistemas diferentes, com controle de acesso por sistema e por setor.
- **Painéis operacionais** para a equipe de TI: servidores, backups, atualizações e chaves de licença.

Esses projetos são privados. Aqui no GitHub ficam meus projetos pessoais e acadêmicos.
